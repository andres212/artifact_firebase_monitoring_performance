# Integración Firebase Monitoring Performance

Aplicación desarrollada en **Kotlin**, para integrar **Firebase Performance Monitoring** para registrar trazas personalizadas y eventos de usuario.

---

![Screen Dashboard](https://imgur.com/a/qDlRDXw)

## Características

- Integración completa con **Firebase Performance**
- Uso de **trazas personalizadas** para medir tiempos de ejecución
- Ejemplos de eventos al realizar acciones del usuario

---

## Tecnologías utilizadas

- **Kotlin**
- **Android Jetpack (ViewModel, LiveData, ViewBinding)**
- **Firebase Performance Monitoring**
- **Gradle 8+**
